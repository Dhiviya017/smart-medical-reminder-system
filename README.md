# Smart Medical Reminder System for Medication Adherence and Health Monitoring

## 📌 Overview

A smart medical reminder system developed using Arduino Uno to help users follow their medication schedule and monitor basic health parameters.

The system provides medication reminders through an LCD display and buzzer, supports scheduled medicine access through a pill dispenser, and uses a GSM module to send SMS notifications. A pulse sensor and temperature sensor are used for basic health monitoring.

## 🎯 Objectives

* Provide timely medication reminders.
* Assist with scheduled medicine access.
* Monitor pulse and temperature.
* Send SMS notifications using GSM.
* Provide real-time information through an LCD display.

## ⚙️ Working

1. The Arduino Uno acts as the main controller.
2. The system provides medication reminders based on the programmed schedule.
3. The buzzer alerts the user when medication is due.
4. The LCD displays relevant information.
5. The pill dispenser assists with scheduled medicine access.
6. The pulse and temperature sensors collect basic health data.
7. The GSM module can be used to send SMS notifications.
